# Agent Pipeline 0.3.0 · Follow a run

Open the run monitor to see the latest recorded activity and its observation time on a running step. Open the active native agent’s session directly from its card. Waiting steps name their outstanding dependencies and show pending questions or approvals.

The monitor and Results now count steps consistently. A skipped conditional branch has its own counter. A finished run with a skipped branch shows zero remaining steps. Expand Acceptance on a selected step to see recorded exit codes or which checks still lack a result.

Install the plugin with `orca plugin install Alexander-64/orca-pipeline@v0.3.0 --json`. For standalone execution, install the release tarball with `npm install -g ./orca-agent-pipeline-0.3.0.tgz` and run `pipeline ui`.
