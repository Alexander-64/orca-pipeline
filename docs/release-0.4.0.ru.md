# Agent Pipeline 0.4.0 · Шаблоны, репетиция и приёмка изменений

- В библиотеке панели можно сохранить сценарий с параметрами и открыть его для другого проекта. Встроенный шаблон последовательно запускает аудит, подготовку улучшений и независимую проверку.
- Репетиция до запуска показывает результат условий и объединения веток на заданных пользователем данных. Можно смоделировать ошибку шага и увидеть, где понадобится ручное подтверждение.
- При передаче шага следующему агенту монитор показывает причину, предыдущий отчёт и фрагмент подготовленного контекста. Из передачи можно открыть обе нативные сессии.
- В итогах можно выбрать исходный прогон и сравнить его с другим из истории. Видны различия в шагах, строках отчёта, списках файлов и результатах проверок.
- После успешного запуска в отдельной Git-копии можно просмотреть diff и принять его в индекс исходного проекта. Консоль поддерживает тот же порядок через `run --isolated`, `diff` и `accept --digest`. Приёмка проверяет хеш патча, исходный коммит и состояние затронутых файлов.
