# Agent Pipeline 0.3.0 · Наблюдение за прогоном

Карточка активного шага показывает последнее наблюдение и его время. Из карточки можно открыть сессию нативного агента Orca. У ожидающего шага видны названия незавершённых зависимостей, запрос на ответ или подтверждение.

Монитор и «Итоги» используют общий подсчёт шагов. Пропущенная по условию ветка показана отдельно. После завершения прогона с пропущенной веткой осталось ноль шагов. В списке проверок виден записанный код завершения или отсутствие результата.
